# tagStudio —— 本地素材标签管理器

给视频 / 音频 / 图片**人工打标签**，按标签浏览，并且**把标签直接写进文件名**：

```
助眠-直播录屏-轻语-b5f072a6867d1b93e2ae05f11dce1e5f.mp4
│    │        │    └── uuid：32 位十六进制，全局唯一，永远不变
│    │        └────── 后面的标签：补充特点，按你输入的先后
└────┴─────────────── 第一个标签：主要特点
```

这么做的唯一目的是：**文件离开这个软件之后，标签还在。** 拷到 U 盘、发到手机、
丢进电视、用资源管理器看，文件名本身就是标签，不需要任何配套文件、数据库或播放器支持。

**没打标签的素材不改名**，保持你原来的文件名（界面上带「待分类」角标）；
只有打上标签才会被改名，而**入库时的原始文件名一直记着**，界面上随时能看见、也能搜。

---

## 一、快速开始

1. 双击 **`start.cmd`**（会自动开浏览器到 <http://127.0.0.1:8787/>）。
   也可以在命令行里 `node server.js`。
2. 首页选择**素材文件夹**（点「浏览…」弹出 Windows 的目录选择框，或直接粘贴路径）。
   空文件夹也行，程序会自动建库。**素材库可以是任意目录**；打开之后想换，
   点**左上角的库路径**就能重新选，旁边的下拉框可以直接跳回**用过的文件夹**（见第四节）。
   你给的两个视频已经放在 **`素材\`** 里了，第一次直接选这个文件夹就能用。
3. 像过卡片一样过素材：点卡片 → 输标签（逗号分隔，或点下面的建议标签）→ **保存并重命名**。
4. 要拿走时点右上角 **导出…** → 选目标文件夹（例如 U 盘盘符）→ 开始导出。

> 需要 Node.js 18 以上。除了 Node 本身，**没有任何第三方依赖**，不需要 `npm install`。
> 视频缩略图需要 ffmpeg；找不到也能用，只是视频显示成占位图标（本机已有
> `E:\workbench\ffmpeg\bin\ffmpeg.exe`，会被自动找到）。

## 二、命名规则

### 2.1 格式

```
标签1-标签2-...-<32位uuid>.<原扩展名>
```

- **扩展名原样保留**（`.mp4` / `.MP3` / `.PNG`…，大小写和原来一致），图片、音频、
  视频、以及"其它"任何类型都一视同仁。`.tar.gz` 只认最后一段（`.gz`）。
- **uuid 32 位小写十六进制，全局唯一**，一个素材一辈子不变。
- **没打标签的素材不改名，保持你原来的文件名。** 这是有意的：原始名字是你判断
  "该打什么标签"的唯一线索，一进库就被改掉的话，你就不知道哪个是哪个了。
  界面上这类素材会带一个「待分类」角标，左侧「未打标签」一点就能全列出来；
  **一旦打上标签，才会被改名成 `标签-uuid.扩展名`**。
- 库里同一时刻不会有两个文件重名（同名会自动分配新 uuid），所以 uuid 是全局唯一的。

### 2.2 标签的顺序就是主次

文件名按你输入的顺序写，**不再按码点重排**。先打「轻语」再打「助眠」，
文件名就是 `轻语-助眠-<uuid>.mp4`：第一个标签是这段素材的主要特点，后面的是补充。

同一组标签、同一个顺序，反复保存不会改名。把顺序调过来（先「助眠」后「轻语」）
会改名，这是有意的。已经命名好的文件保持原样，不会在扫描时被批量重排。

筛选和合集不看顺序：点「助眠」再点「轻语」，两种顺序的素材都会出现。
批量加上去的标签接在每条现有标签的末尾，不抢原来的主标签。

### 2.3 标签的合法字符

因为标签会变成文件名，所以有硬性限制：

| 规则 | 原因 |
|------|------|
| 不能含 `-` | 它是标签之间的分隔符，含了就切不回来 |
| 不能含 `.` | 会把扩展名切乱 |
| 不能含 `/` `\` `:` `*` `?` `"` `<` `>` `\|` 和控制字符 | 文件名非法 |
| 不能是 `CON` `PRN` `AUX` `NUL` `COM1-9` `LPT1-9` | Windows 保留设备名，建不出来 |
| 最长 40 个字符 | 保证多个标签拼一起还有余地 |

**允许**中文、日文、emoji、空格、`_ + ( ) [ ] { } & @ # ! $ ' ’ “ ” · 、 ， 。 ？！《》 〈〉 「 」 【 】`

### 2.4 太长会怎样

两条硬线：

- **单个文件名**按 UTF-8 **字节**算，给标签留 180 字节（中文一个字 3 字节）。
- **完整绝对路径**不超过 250 个字符 —— 因为 Windows 默认 `MAX_PATH=260`，
  而且"用数据线拷到别的设备"这个场景下不能指望对方开了长路径支持。

超了怎么办：**从末尾开始丢标签**（末尾是次要特点，先丢），丢到只剩一个还超，才截断这个标签。
**uuid 和扩展名永远不裁**。被丢掉的标签会在界面和导出体检里明确列出来，不会悄悄丢。

## 三、别人打过的标签，我们能认回来

**场景**：你以前用这个工具（或者别的工具）给一批素材打过标签，文件名长这样 ——
`旅行-风景.mp4`、`助眠-直播录屏-轻语.mp3`，**里面没有那串 uuid**。
换台设备、或者换一个文件夹打开，这些标签名字就散了。

打开这种文件夹时，程序会**自己认出来**，然后在顶栏亮一个按钮：
「认出 N 个文件名里的标签」。点开是一个**确认弹窗**：

- 按**标签组合**分组显示（同一组标签的素材归在一起，显示有几项、共多大）
- 每个素材列出「现在的文件名 → 采纳后会变成什么」，**前面有一个勾选框**
- **认出来的标签本身也是勾选框**（在每组组头上，默认全勾）：一组里不像标签的词可以直接取消，
  比如 `助眠-直播录屏-轻语.mp3` 里你只想留「助眠」「轻语」，就把「直播录屏」的勾去掉，
  预览的规范名会立刻从 `助眠-直播录屏-轻语-<uuid>.mp3` 变成 `助眠-轻语-<uuid>.mp3`。
  **一组的标签全取消，这一组就整个灰掉、不会被改**
- 顶部一个「全选」；每组组头还有一个「整组」，一组几条时不用一个个点
- 不确定的那几条**把勾去掉就行**，它们会保持现在的文件名，你以后想认再打开这个弹窗
- 底部按钮：`采纳勾选的 N 个` / `勾选的 N 个别再问` / `都先不用` / `关闭`
  （一个都没勾时「采纳」是灰的；「别再问」只对你勾上的那些生效，不采纳的会记住，不再打扰）

**为什么要你确认，而不是自动打好**：`旅行-风景.mp4` 这种名字也可能是你自己起的，
比如 `2024-08-23 直播录屏.mp4` 就长得很像标签。**自动改错名字比不改名糟糕得多**，
所以这一步永远由你勾、你点。程序只会：

1. 认出来 → 提示你；
2. 你勾上并点「采纳」→ 才把标签写进索引，并顺手把文件名补成规范的
   `标签-uuid.扩展名`（**原文件不会被删、不会被移动**，只是改名）；**没勾的一个都不动**；
3. 你点「别再问」或「都先不用」→ 什么都不做，而且这个决定被记住（文件名以后再变才会重新问一次）。

下面这些**不会**被当成标签（都是实测过的）：`单段.mp4`（只有一段）、
`带.点-标签.mp4`（段里有点）、`2024-08-23 直播录屏.mp4`（数字开头）、
`旅行-风景-<uuid>.jpg`（已经是本工具的规范名，不用再认）、没有扩展名的文件、隐藏文件。

## 四、界面

| 区域 | 干什么 |
|------|--------|
| 顶栏 | **库路径（点它换素材文件夹）+ 右侧「用过的文件夹」下拉框** / 搜索（文件名·标签·路径）/ 类型筛选 / 排序 / 重新扫描 / 导出 / 设置 |
| 左栏 | 库统计、`全部`·`未打标签`·`清空筛选`、**合集**、**标签列表**（点标签 = 叠加筛选，再点取消） |
| 主区 | 卡片网格 + 缩略图（视频是 ffmpeg 抽帧，音频是音符图标），每张卡片左上角勾选框 |
| 底部条 | 选中数量/体积、批量加标签、批量移除标签、导出所选 |
| 标签编辑器 | 媒体预览（视频可直接播）、重命名实时预览、已有标签点选、保存 |

> 界面截图不入库。本机跑 `node capture_demo.js` 会用 `素材/` 里的真视频现跑一遍，
> 把 7 张图写到 `截图/`（那 7 张图对应的操作顺序就是下面 4.1～4.7 讲的东西）。

### 4.1 换素材文件夹（左上角）

切换素材库的入口就在**左上角那个路径**上，不用进设置：

- **点路径本身** → 打开目录浏览器，挑一个文件夹就切过去（也可以在里面点「用系统对话框」）。
- **右边的下拉框** → 列出**以前打开成功过的素材文件夹**（最新在最前，最多 10 个），
  选中即刻切换。这个列表记在 `data\config.json` 里，**关掉程序、重启电脑都还在**。
- 列表最后一项是「选择其他文件夹…」，等于点路径。
- **切库不会动上一个库的任何东西**：每个库的标签、缩略图缓存都各自存在自己目录的
  `.mtag\` 里，换回来还是原样。注意打开一个文件夹会真的扫描并按规则给**已打标签**的
  素材改名（未打标签的保持原名），所以别拿存着重要素材、已经被别的软件管理的目录来试。

**筛选是叠加的（AND）**：点「助眠」再点「轻语」，得到同时有这两个标签的素材。
用 `any` 参数（界面上"任一标签"）可以做 OR。搜索框回车立即生效。

**打完标签后怎么看"这原本是哪个文件"**：素材一旦打上标签就被改名成 `标签-uuid.扩展名`，
所以程序把**入库时的原始文件名**一直记着，在四个地方给你看：

| 位置 | 显示什么 |
|------|---------|
| 卡片（已改名的才有这一行） | 文件名下面一行浅色小字，就是原始文件名 |
| 卡片角标 | 还没打标签的显示「待分类」（缩略图左下角，标签行尾部也有一个） |
| 标签编辑器 | 标题是当前文件名，下面单独一行显示原始文件名 |
| 底部选择栏 | 选中的素材里有改过名的，会提示「含 N 个已改名素材」 |

**搜索框也认原始文件名**：比如原来是 `一首歌.mp3`、现在叫 `旅行-海边的日落-<uuid>.mp3`，
搜「一首歌」照样能搜到它。

**合集**是常用标签组合的快捷方式：现在筛好一组标签，点「用当前筛选保存合集」，
下次一键切回。

## 五、导出（就是"复制到一个文件夹，用数据线拷走"）

「导出」做的事是**复制**，**原文件一个都不动**。

- **导出范围**：勾选的素材（有勾选时）／当前筛选的全部／整个库。
- **目标文件夹**：任意位置，比如 U 盘根目录。默认是库里的 `.mtag/exports/`。
- **子目录**：留空自动用 `导出-日期-时间`（如 `导出-20261015-201407`），
  所以连着导两次不会搅在一起。
- **命名方式**（三选一）：
  | 选项 | 结果 |
  |------|------|
  | 标签-uuid.扩展名 | 和库里一致，推荐 |
  | 原始文件名 | 恢复成入库之前的名字（含原来的子目录结构） |
  | 标签-新uuid | 同样带标签，但每次导出发一个新编号 |
- **顺带打个 zip**：给不方便拷一堆散文件的场合。
- **导出前体检**：开始前先告你「将复制 N 个文件 / 共多少」，
  以及 **缺失源文件 / 超长路径 / 被截断的标签** 三类风险。
- **进度**：实时进度条 + 日志（走 SSE，能中途取消）。
- **产物**：素材文件 + `manifest.csv`（带 UTF-8 BOM，Excel 直接打开不乱码）
  + `manifest.json`（给程序读的）。

**重复导出不会覆盖**：如果目标文件夹里已经有同名文件，会自动加 `(2)`、`(3)` 后缀。

## 六、数据放在哪 / 会不会丢

库里会多出一个隐藏目录 `.mtag/`：

```
你的素材库/
├── 轻语-b5f072a6867d1b93e2ae05f11dce1e5f.mp4   ← 你的素材（唯一被改名的东西）
├── 收藏-206b012c295edd227f7b3439cac55a3d.mp4
└── .mtag/                      ← 程序的数据，删掉也不影响素材本身
    ├── db.json                 ← 索引：uuid ↔ 路径 / 标签 / 大小 / 时间
    ├── 把素材放这里.md          ← 给你看的说明
    ├── journal/                ← 改名预写日志（崩溃自愈用）
    ├── thumbs/                 ← 缩略图缓存，删了会自动重建
    └── exports/                ← 默认导出位置
```

### 不会把标签搞丢的三道保险

1. **文件名里有 uuid** —— 只要文件名没被改烂，一定能认回来。
2. **文件名能被反解** —— 就算 `db.json` 整个丢了，重新扫描时规则名会被重新解析出标签
   （`助眠-轻语-<uuid>.mp4` → 标签 `助眠`、`轻语`；旧版本留下的 `未分类-` 开头名也会被
   正确识别为"没标签"）。
3. **大小 + 修改时间指纹** —— 防的是"你在外部把文件名改了"：扫描时会拿
   `size:mtimeMs` 去找唯一候选，接得上就把标签续上。

### 改名是安全的

每次改名走**预写日志**：先写日志 → `fs.rename` → 更新 `db.json` → 删日志。
任何一步断电，下次启动都会自愈（续做、补记账、或按磁盘事实裁决），
**绝不会出现"库里记着、磁盘上没有"的幽灵素材**。

`db.json` 本身也做**原子写**（写临时文件再 rename）。万一它真的坏了
（手改坏、编辑器写坏、磁盘出问题），程序**不会**把它当成"新库"覆盖掉 ——
那样等于把标签悄悄清空。它会：把坏文件改名成 `db.json.损坏-xxxxxxxx` 留底，
然后拒绝打开这个库，并在界面上告诉你原因和处理办法。这时你可以：

- 把留底文件改回 `db.json`（能修就修好），或者
- 直接删掉它重新建库 —— 素材一个都不会少，标签也能从文件名反解回来。

### 恢复时"最少的手工操作"

删掉 `.mtag/` 之后重新打开这个库，标签会按文件名全部反解回来（第 2 道保险）。
还没打标签的素材会一直保持你原来的文件名，不会被程序动过。

### 从别的设备搬过来的素材，标签还能找回来吗

能，但要你点一下确认 —— 见上面第三节：
文件名里的标签会被认出来，程序弹窗问你「要不要按这个打标签」，你点了才会写进去。
`uuid` 丢了也不要紧，标签就在文件名里。

## 七、常见问题

**Q：能改回原来的文件名吗？**
能。导出时选「原始文件名」，`db.json` 里记着每个素材入库前的原始相对路径。

**Q：我手动把文件改名了，标签会丢吗？**
一般不会。只要文件名里还留着那 32 位 uuid，或者大小+修改时间唯一匹配得上，就能认回来。
两样都没有才会当新素材。

**Q：换素材库怎么办？**
点左上角的库路径换一个文件夹，或者用旁边的下拉框跳回用过的文件夹（见 4.1）。
每个库有自己独立的 `.mtag/`，互不干扰，打开成功过的路径都会被记住。

**Q：会联网吗？会上传吗？**
不会。服务只监听 `127.0.0.1`，全程本地；连第三方依赖都没有。

**Q：支持多少素材？**
扫描上限 20 万文件；几千到几万条元数据用 JSON 完全够（更大量需要换存储）。

**Q：视频缩略图不显示？**
把 `ffmpeg.exe` 放到 `tagStudio/bin/` 下，或设环境变量 `FFMPEG_PATH`。
不放也能正常用，只是视频卡片是占位图标。

**Q：端口被占 / 不想自动开浏览器？**
`node server.js --port 9000 --no-open`。其它参数：`--root <路径>` 直接指定库、
`--scan-interval 0` 关掉自动扫描（默认每 45 秒一次）。

**Q：`start.cmd` 双击没反应 / 报一堆乱码？**
直接在该目录开命令行跑 `node server.js`（效果完全一样）。
（历史说明：这个脚本原先叫 `启动.cmd`，文件名含中文。中文 Windows 的控制台代码页是 936，
实测带中文名的批处理在某些环境下 `cmd` 会解析出错 —— 所以它现在改名为纯 ASCII 的
`start.cmd`，**内容**也全部是纯 ASCII。见验证报告 4.14。）
