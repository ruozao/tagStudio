# 把素材放这里

这个目录是 tagStudio 的默认素材库，你的原始视频 / 音频 / 图片放进来即可。

为了不把几百 MB 的媒体文件塞进 git 仓库，`.gitignore` 里把 `素材/` 下的内容
排除了，只保留本说明文件。所以你 clone 下来之后，需要自己把素材拷进来。

## 怎么用

1. 双击项目根目录的 `start.cmd`（或命令行 `node server.js`）。
2. 首页「素材文件夹」填这个目录的完整路径 —— 直接粘贴即可，例如：
   `E:\workbench\workbench_deepseek\tagStudio\素材`
3. 程序会自动建库（生成 `.mtag/` 隐藏目录），并给还没分类的文件改名为
   `未分类-<32位uuid>.<原扩展名>`。
4. 点开卡片打标签、保存 —— 文件名会变成 `标签1-标签2-<uuid>.<扩展名>`。

## 关于 .mtag

打标签之后这里会多出一个 `.mtag/` 隐藏目录，里面是索引、缩略图缓存和导出产物。
它**可以随时删掉**：删了之后重新扫描会靠文件名里的 uuid 和标签把信息认回来
（见 README「数据放在哪 / 会不会丢」一节）。所以 `.mtag/` 也不进版本库。

## 注意

- 本程序会**真的改磁盘上的文件名**（这正是它的用途）。
- 打标签之前建议先备份素材，或者先在少量文件上试一遍。
